# RK International Language Academy — Official Web Platform

The official, SEO-optimized web application for **RK International Language Academy** (The Way of Success), based in Kilinochchi, Northern Province, Sri Lanka.

## Architecture

- `frontend/`: Next.js 15 App Router, TypeScript, Tailwind CSS, Lucide Icons.
  - `src/globalcss/`: Dedicated global styling (`globals.css`, `theme.css`, `typography.css`, `animations.css`).
  - `public/images/`: Structured media assets (`logo/`, `courses/`, `trainers/`, `results/`, `campus/`).
  - `src/components/`: Modular UI, layout, section, form, and SEO components.
- `backend/`: Configuration, MongoDB Mongoose data models (`Course`, `Batch`, `Enquiry`, `Student`, `Trainer`, `Testimonial`, `Post`, `Setting`, `User`), controllers, and email notification services.
